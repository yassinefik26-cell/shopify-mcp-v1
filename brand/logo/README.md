# DRIPHOPE icon concepts

Four standalone icon/monogram directions for use as favicon, app icon and
social profile picture. Each is a 256x256 square SVG with a transparent
background. Brand red is `#E3242B`, taken from the live theme settings.

| # | Name | Idea |
|---|------|------|
| 01 | Drop D | The D's counter is the drip |
| 02 | DH Lock | H and D share a stem; red crossbar carries the wordmark's accent rule |
| 03 | Hard Drip | Faceted drop split white/red, bar knocked out near the base |
| 04 | Cut D | D sliced by the red rule, halves offset |

## Variants

- `*-color.svg` — white + red, for screen
- `*-mono-white.svg` — single ink on dark
- `*-mono-black.svg` — single ink on light

The mono files are not just recolours. In 01 the drip stays a hole and in 04
the slice stays an open gap: filling either with the same ink as the body
collapses the mark into a solid shape. 02's crossbar is structural, so it is
present in every variant.
